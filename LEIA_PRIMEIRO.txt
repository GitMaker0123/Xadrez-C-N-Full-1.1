XADREZ CUSTOM FULL 1.4 — MCE1809
================================

Esta é uma atualização do seu aplicativo web instalável (PWA), e NÃO um APK.
Funciona no navegador, pode ser instalado na tela inicial e não precisa de servidor para partidas contra bot e treino.

NOVIDADES
- Som de movimento estilo “tec-tec” (estalos sintetizados no navegador), captura, xeque e fim de partida.
- Movimento suavizado: a imagem da peça desliza da origem até o destino, com preferência por reduzir movimento respeitada.
- Escolher Brancas, Pretas ou Cor aleatória. Se escolher Pretas contra o bot, o bot com Brancas começa.
- Treino com dicas básicas de jogadas; não altera Elo nem XP.
- Elo recreativo começando em 600 para novos jogadores. Preserva Elo da 1.3 se já houver partidas pontuadas.
- XP por VITÓRIA contra bot, barra de XP e nível numérico. Outros modos não alteram Elo/XP.
- Aparência: seleção de peças brancas ou pretas; importar PNG/WEBP/JPG e cores do tabuleiro.
- Biblioteca de temas: Tema Custom #1, #2 etc.; salvar, renomear, carregar e excluir.
- Não é possível salvar o visual padrão sem alteração nem dois temas visualmente idênticos.
- Exportar/importar o pack atual (.json) como cópia de segurança.
- O multiplayer WebRTC da 1.3 continua experimental, com pareamento manual por códigos.

PUBLICAR / ATUALIZAR NO GITHUB PAGES
1. Faça backup dos seus arquivos atuais do repositório, se quiser.
2. Extraia o ZIP. Envie os arquivos DE DENTRO da pasta Xadrez_Custom_FULL_1_4 à RAIZ do mesmo repositório no GitHub.
3. Substitua os arquivos de mesmo nome: index.html, game.js, engine.js, peer.js,
   style.css, manifest.webmanifest, sw.js, icon-192.png, icon-512.png.
4. Salve as alterações (Commit changes). O GitHub Pages continua ativo automaticamente.
5. Abra o link do jogo, atualize o navegador e, se estiver instalado como PWA, feche e reabra.
   Se continuar vendo a versão 1.3, atualize novamente após o navegador detectar o novo Service Worker.

COMO SALVAR TEMAS
- Abra “Aparência do jogo → Meus temas salvos”.
- Troque pelo menos uma coisa: tabuleiro, cor das casas, pack de peças ou PNG de uma peça.
- O campo de nome pode ficar em branco: gera Tema Custom #1, #2 etc. automaticamente.
- Clique em “+ Salvar tema novo”.
- Selecione um tema salvo para carregar, renomear ou excluir.
- Os visuais são armazenados NO NAVEGADOR daquele aparelho, não no GitHub.
- Faça backup exportando um pack JSON, especialmente antes de limpar dados do navegador.
- As imagens importadas são reduzidas para 256x256 para economizar espaço; há limite de armazenamento do navegador.

OBSERVAÇÕES
- Os efeitos sonoros dependem das permissões e do volume do navegador.
- A animação depende de suporte do navegador a animações Web e é desativada se o sistema preferir reduzir movimento.
- Os cálculos de Elo/XP são locais, recreativos e NÃO constituem classificação oficial.
- O bot Muito difícil é uma IA local leve, não um motor profissional de xadrez.
- Multiplayer entre navegadores segue EXPERIMENTAL e não foi validado em A31/A51.
- Não foram incluídas imagens de packs de terceiros. Você pode importar seus PNGs no editor.
